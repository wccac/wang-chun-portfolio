# 王淳 · 创作小屋

以像素小屋为入口的交互作品集，展示檀晷香事、BITTER MELON 苦瓜主题书籍和绣境花园。

## 浏览

从网站根目录进入小屋，或直接打开以下相对路径：

- `portfolio/index.html#cottage` — 小屋首页。
- `portfolio/index.html#desk` — 工作桌；点击苦瓜书上的圆圈，体验拿书、翻开与双指放大。
- `portfolio/index.html#tangui` — 檀晷作品。
- `portfolio/index.html#bitter` — 苦瓜书籍作品。
- `portfolio/index.html#panda` — 绣境花园作品及游园短片。

直接打开作品地址或使用作品目录会进入阅读页面；从书桌点击苦瓜书会播放完整翻书，重复访问也不会自动跳过。系统“减少动态”或站内“简化进入镜头”仍受尊重。

## 本地运行

这是静态 HTML、CSS 与 JavaScript 网站，无需安装前端依赖。请在仓库根目录启动 HTTP 服务：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8080/`。不要直接以 `file://` 打开，以保证模块、字体和作品内页正常加载。

## 目录

- `portfolio/`：小屋场景、导航、音乐、翻书和闻香动画、熊猫交互。
- `world-design/`：三套作品的展示页面、详情、图集、字体和滚动效果。
- 根目录的 S01–S06 图像：小屋场景。
- 当前视频所在目录：熊猫游园短片。只包含页面实际引用的视频。

图片、字体、音乐、视频和前端库均随网站使用相对路径，支持发布到域名根目录或子目录。

## 交互与当前版本

- 进入房间后，以可见圆圈作为作品入口。
- 翻书使用约 5.05 秒的连续镜头；手指放大与页面同步，退手在放大末段完成。
- 檀晷包含闻香、眩晕、倒地及进入作品的叙事动画。
- 熊猫短片由用户点击播放，作品画廊支持大图查看与章节导航。
- 详情返回保留阅读位置，图片查看器沿原图位置展开和收起。
- 音乐及交互音效默认启用；浏览器可能要求首次点击后才能发声。
